# 城市级三维资产渲染与 GIS 数字孪生测试报告

## 一、测试对象

测试资产：Manama Bahrain 3D City Map Model  
资产来源：Fab  
资产链接：https://www.fab.com/listings/5510a570-4a07-481a-879e-ef3f49892221

该资产用于模拟城市级三维 GIS 场景底座，重点测试建筑白模、道路网络、
商业与住宅区域、水系和绿地等典型城市要素在 Unreal Engine 5 中的实时
渲染、漫游交互和空间管理效果。

## 二、测试目标

1. 验证城市级三维资产在 UE5 场景中的导入、摆放和整体渲染效果。
2. 验证第一人称视角下的城市漫游、碰撞检测和空间对象交互能力。
3. 验证大规模建筑密集区域下的实时渲染性能和可优化方向。
4. 为后续 GIS 数据接入、POI 标注、空间测距和数字孪生场景管理提供工程基础。

## 三、场景组织方式

项目将城市模型作为三维底座资产导入默认地图，并按照 GIS 数字孪生系统的
思路进行组织：

- 建筑白模：作为主要城市空间体量，用于测试密集建筑区域渲染效果。
- 道路网络：作为城市通行结构，用于验证第一人称漫游路线和空间遮挡关系。
- 水系区域：作为地表要素，用于验证不同材质和后期处理表现。
- 绿地区域：作为城市公共空间，用于验证开阔区域与密集建筑区域的渲染差异。
- POI 点位：使用 C++ `GISPointMarker` 类进行抽象，后续可对应地标、道路节点、
  商业区入口、公共设施等空间对象。

## 四、C++ 支撑模块

本项目新增 `UE5GISScene` C++ 模块，将原有交互 Demo 包装为 GIS 数字孪生
方向的混合开发项目。

### 1. GISDigitalTwinSubsystem

负责维护场景地理原点，并提供经纬度到 UE 世界坐标的轻量转换接口。该类
用于模拟真实 GIS 系统中的空间参考和坐标转换流程，使 POI、城市资产锚点和
测量工具可以使用统一空间基准。

### 2. GISCityAssetAnchor

用于记录城市级三维资产的来源、资产名称、Fab 链接、覆盖范围、锚点坐标、
HLOD 和 Nanite 优化策略等信息。该类可以放置在关卡中作为城市模型的逻辑锚点，
便于说明资产导入和场景组织流程。

### 3. GISPointMarker

用于表示城市兴趣点和空间对象标注。点位包含编号、名称、类别、经纬度坐标
和颜色信息，可扩展为 UI 弹窗、属性面板、图层控制和点击查询功能。

### 4. GISMeasurementTool

用于计算三维空间距离和水平距离。该功能可包装为 GIS 场景中的测距工具，
适用于建筑间距、道路宽度、点位距离和巡检路线长度等基础空间分析。

## 五、渲染测试内容

### 城市级三维资产渲染测试

- 导入城市级三维资产（建筑白模、道路网、水系、绿地），测试大规模场景下
  的实时渲染性能。
- 调整材质、光照与后期处理参数，优化城市场景渲染效果。
- 在城市场景中验证第一人称漫游与空间碰撞检测功能。

*图：城市密集建筑区域实时渲染测试效果*

### 大规模场景性能关注点

- 建筑数量较多时，关注视口帧率、阴影开销、材质复杂度和可见对象数量。
- 城市道路和建筑交界区域，关注碰撞体是否影响漫游流畅度。
- 开阔水系和绿地区域，关注反射、后期处理和天空光照对整体画面的影响。
- 密集建筑区域，关注遮挡剔除、HLOD、Nanite 和实例化静态网格的优化空间。

## 六、GIS 与数字孪生扩展方向

1. 真实地理坐标接入：将城市资产锚点经纬度与真实地图坐标对应。
2. POI 图层：按建筑、道路、水系、绿地、公共设施等类别显示或隐藏标注。
3. 属性查询：点击建筑或 POI 后显示名称、类别、坐标、面积和用途等信息。
4. 空间测量：支持点到点距离、道路宽度、建筑间距和路径长度测量。
5. 路径漫游：基于道路网络设计巡检路线、自动漫游路线或任务点导航。
6. 数字孪生数据：后续可接入交通、人流、设备状态和环境传感器数据。

## 七、测试结论

通过城市级三维资产测试，项目从普通第一人称交互 Demo 扩展为具备 GIS
可视化和数字孪生雏形的 UE5 三维场景系统。当前工程已经具备城市资产承载、
第一人称漫游、空间碰撞、POI 抽象、坐标转换和距离测量等基础能力，后续可在
此基础上继续接入真实 GIS 数据和业务属性，形成更完整的城市数字孪生原型。
